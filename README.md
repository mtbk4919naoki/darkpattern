# ダークパターン事例イラスト集（静的サイト）

消費者庁関連のリサーチ・ディスカッション・ペーパー「いわゆる『ダークパターン』に関する取引の実態調査」に基づくイラスト集（`caa_futurer101_0407_03.pdf`）を、目次1ページと事例①〜⑮の15ページで閲覧できる静的サイトです。

## 構成

- `index.html` — 目次・免責
- `cases/01.html` … `cases/15.html` — 各事例（定義・【例】・イラスト）
- `css/style.css` — 共通スタイル
- `assets/img/` — PDF から抽出したイラスト

ビルドツールは不要です（HTML + CSS のみ）。

## ローカルで表示

```bash
cd darkpattern
python3 -m http.server 8080
```

ブラウザで http://localhost:8080/ を開きます。
