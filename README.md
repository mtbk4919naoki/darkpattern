# ダークパターン事例別検討資料

公開サイト: https://mtbk4919naoki.github.io/darkpattern/

消費者庁の調査資料を参考に、個人で作った学習用の静的サイトです。目次と事例①〜⑮を、ブラウザだけで読めます。消費者庁の公式資料ではなく、公式見解や特定の事業者を示すものでもありません。

## 見方

目次から各事例を開きます。事例ページでは、次の3つを切り替えます。

- 概要 … 参考資料の説明とイラスト
- ダークパターン事例 … 操作できる例
- 改善例 … 同じ場面の改善案

解説はタブの外にあり、どのタブでも表示されます。タブはページの上部と下部にあり、どちらを押しても切り替わります。

アドレスの末尾で、開くタブを指定できます。

- `#overview` 概要
- `#dark` ダークパターン事例
- `#good` 改善例

## ローカルで開く

ビルドは不要です。このリポジトリのルートで次を実行します。

```bash
python3 -m http.server 8080
```

ブラウザで http://localhost:8080/ を開きます。

## 中身

- `index.html` 目次
- `cases/01.html` から `cases/15.html` 各事例
- `css/` 見た目。色や余白の定義は `css/tokens.css`
- `js/main.js` タブ、サイドバー、操作例
- `assets/img/` 参考資料のイラストと、操作例で使う画像
- `DESIGN.md` 色・文字・余白の決めごと
- `AGENTS.md` このリポジトリを直すときのルール

CSS の土台に [Open Props](https://open-props.style/) を同梱しています。
